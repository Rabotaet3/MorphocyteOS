# Сборка MorphocyteOS

## Требования

- Windows x64 и .NET SDK 10.0.401 (закреплён в `Source/global.json`).
- Доступ к NuGet для первого восстановления зависимостей.
- Для поставляемого `mihomo.exe` Go не нужен: проверенный бинарник находится в `Source/Packaging/Engine`. Для его пересборки см. `Source/Packaging/ThirdPartySource/README.md`.

## Чистый комплект

Из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Release.ps1
```

Скрипт запускает регрессионные проверки, проверки обновлений и WPF-сценарии с безопасным тестовым ядром. Они не подключаются к VPN-серверу. Настоящее комплектное ядро используется также для проверки синтаксиса профилей без запуска TUN.

Результат находится в `artifacts/1.0.0`: папка программы, ZIP для Windows x64, ZIP исходников, описание релиза и один файл SHA-256. Приложение публикуется самостоятельно запускаемым EXE со встроенной .NET Runtime 10.0.12. Mihomo остаётся отдельным EXE.

Для другого каталога:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Release.ps1 -OutputDirectory D:\Releases\MorphocyteOS-1.0.0
```

Каталог результата должен быть пустым или отсутствовать. Скрипт не очищает существующие файлы: это защищает пользовательские профили от случайной перезаписи и исключает примесь старого содержимого к релизу. Для повторной сборки укажи новую пустую папку.

В комплект и архив исходников входят только явно выбранные файлы. `.preview`, `bin`, `obj`, тестовые сборки, настройки, журналы, `portable.flag` и личные YAML не включаются. Не используй ZIP всей рабочей папки для публикации.

## Изменения и выпуск

Меняй исходники только в `Source/MorphocyteRouter`. Проекты `RouterRegressionTests`, `UpdateServiceTests`, `RouterIntegrationTests` и `FakeMihomo` служат для проверок. `Source/build.ps1` собирает только комплект программы; `Scripts/Release.ps1` дополнительно готовит архивы и контрольные суммы.

Версия приложения задаётся в `Source/MorphocyteRouter/MorphocyteRouter.csproj`. При её изменении обнови README и описание релиза. При смене Mihomo обнови фиксированный SHA-256, соответствующие исходники и лицензии; при смене .NET Runtime — её закреплённую версию и лицензионные уведомления.

Перед публикацией проверь новый комплект вручную: импорт своего профиля, запуск и остановку VPN, применение правил и закрытие крестиком. Не переноси созданные при проверке файлы в ZIP. Проверки с тестовым ядром не заменяют проверку реального подключения, драйверов и совместимости с другими VPN.

Скрипты ничего не отправляют в GitHub, не создают теги и не публикуют релизы.
