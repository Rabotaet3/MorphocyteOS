# MorphocyteOS 1.2.3

- Исправлен сбой обновлятора: приложение больше не закрывается до начала установки из-за ошибки запуска WPF.
- Обновление заменяет файлы комплекта в той же папке, из которой запущен EXE, и повторно запускает приложение. Название папки может быть любым.
- Перед закрытием приложение ждёт подтверждения готовности обновлятора. Если он не запустился, окно остаётся открытым и показывает ошибку.
- Добавлены проверки настоящего WPF-запуска, установки в папку с кириллицей и пробелами, сохранения личной конфигурации и восстановления при занятом файле.

- Исправлены обрезанные стрелки и подпись кнопок отмены/повтора. Настройки и справка остаются видимыми внизу боковой панели при уменьшении окна.

## Обновление с 1.2.1 и 1.2.2

В этих версиях сломан запуск встроенного обновлятора. Один раз закрой приложение и распакуй полный архив `MorphocyteOS-1.2.3-win-x64.zip` в свою папку программы с заменой файлов. Удалять папку, личные профили или настройки не нужно. После установки 1.2.3 следующие обновления можно устанавливать из приложения.

# MorphocyteOS 1.2.2

- **Диагностика подключения** в журнале: проверка ядра, выбранного VPN, сервера, DNS и HTTPS. Результат можно скопировать без профиля, ссылок и ключей.
- **Отмена и повтор изменений правил** — кнопками или Ctrl+Z / Ctrl+Y. Поддерживаются маршруты, включение правил, удаление, перемещение и порядок папок. Перед применением показывается краткая сводка изменений.
- **Обновление подписки** из настроек с сохранением правил, папок и черновика. Доступный выбранный сервер сохраняется; если он удалён, приложение просит подтвердить замену. При сбое обновления возвращается прежняя конфигурация.
- **Восстановление VPN после сна и смены сети.** Включено по умолчанию, отключается в настройках. Ручная остановка отменяет восстановление; неприменённые правила остаются черновиком. Повторные попытки ограничены, посторонние ядра не останавливаются.

# MorphocyteOS 1.2.1

- Маршрут VPN / напрямую / блокировка выбирается в строке правила. Меню раскрывается вниз, оформлено в цветах приложения и поддерживает изменение нескольких выделенных записей. Правила сохраняются в черновике до применения.
- Карточка подключения показывает текущий приём и отдачу, задержку HTTPS-запроса через VPN и долю успешных запросов среди последних 20 проверок. Убраны общий счётчик правил и лишние технические поля.
- Журнал вынесен на отдельную вкладку с активными соединениями и фильтром по процессу, адресу, правилу и маршруту.
- Настройки собраны на одной прокручиваемой странице; кнопки сверху переводят к разделам. Убраны длинные пояснения, исправлены подписи чекбоксов и выход элементов за границы при наведении.
- Крестик всегда сворачивает приложение в трей. Меню значка позволяет открыть окно, управлять VPN, открыть журнал и полностью выйти. Добавлены автозапуск при входе в Windows и подключение последнего сохранённого профиля; черновики автоматически не применяются.
- Автоматическое обновление проверяет стабильные релизы GitHub при запуске и каждые 30 минут. Найденное обновление устанавливается, когда VPN выключен и диалоги закрыты. Уведомление можно отложить; ручная проверка и установка доступны в настройках. Сохраняются проверка SHA-256, личные файлы и откат при сбое.
- Экспорт и импорт настроены через один файл `.morphocyte`: выбранный YAML с подключением, правила, папки, черновик, оформление, параметры запуска и обновлений, локальные ресурсы провайдеров. Импорт создаёт отдельную копию и проверяет конфигурацию и черновик установленным ядром. Прежний профиль сохраняется; импорт подтверждается кнопкой «Сохранить».
- Удалены неиспользуемые обработчики, стили и вспомогательные методы. Проверки импорта используют действующий интерфейс настроек.

## Установка и файлы релиза

Скачай `MorphocyteOS-1.2.1-win-x64.zip`, распакуй весь архив и запусти `MorphocyteOS.exe`. `mihomo.exe` и `release-manifest.json` должны оставаться в комплекте; устанавливать .NET не нужно. После обновления VPN запускается вручную.

В `MorphocyteOS-1.2.1-source.zip` находятся исходники и инструкции сборки. Лицензии и соответствующие исходники Mihomo включены в комплект. `SHA256SUMS.txt` содержит контрольные суммы архивов.

# MorphocyteOS 1.1.1

- Импорт HTTPS-подписок: YAML Clash/Mihomo со списком серверов, JSON Xray и списки VLESS-ссылок, включая Base64.
- Названия VLESS-серверов сохраняются из ссылки, включая эмодзи и кириллицу. Если у одиночного подключения нет названия, приложение предлагает его задать.
- Загрузка не блокирует интерфейс и отменяется при закрытии окна; ошибки не раскрывают приватную ссылку.
- Поддержан импорт при VPN Fake-IP с безопасным разрешением имени сайта; локальные адреса и HTTP-перенаправления запрещены.
- Импорт создаёт отдельный профиль. Из подписки переносятся серверы, а не чужие правила, DNS или настройки контроллера. Личные профили не входят в комплект.

## Установка и обновление

Скачай `MorphocyteOS-1.1.1-win-x64.zip`, распакуй весь архив и запусти `MorphocyteOS.exe`. `mihomo.exe` должен оставаться рядом; устанавливать .NET не нужно.

С версии 1.1.0 можно обновиться через кнопку загрузки в приложении. Установка выполняется после подтверждения перезапуска; активный VPN остановится, затем его нужно запустить вручную. С версии 1.0.0 требуется однократная ручная установка. Настройки и личные профили сохраняются.

Повторно импортируй ранее добавленную VLESS-ссылку, если хочешь перенести её название: прежний импорт его не сохранял. Старый профиль не перезаписывается. Автоматическое обновление содержимого подписки пока не реализовано. URI других протоколов и YAML только с proxy-providers не импортируются.

Архив `MorphocyteOS-1.1.1-source.zip` содержит исходники приложения и инструкции сборки. Лицензии и соответствующие исходники Mihomo включены в комплект. Контрольные суммы архивов — в `SHA256SUMS.txt`. Приложение пока без цифровой подписи; Windows может показать предупреждение SmartScreen.

# MorphocyteOS 1.1.0

- Проверка при запуске и загрузка стабильных обновлений прямо в приложении, с проверкой архива, подтверждением перезапуска и откатом при сбое.
- Безопасная очистка только принадлежащих комплекту устаревших файлов; личные профили, настройки и пользовательское ядро сохраняются.
- Выбор нескольких приложений через Ctrl/Shift и добавление сразу в черновик правил — без изменения YAML до явного применения.
- Компактнее левая панель, убраны повторный логотип и подпись под заголовком; уточнены названия в настройках.

Новый механизм обновлений требует комплекта с `release-manifest.json`. С версии 1.0.0 понадобится однократная ручная установка нового комплекта.

Скачай `MorphocyteOS-1.1.0-win-x64.zip`, распакуй весь архив в отдельную папку и запусти `MorphocyteOS.exe`. .NET устанавливать не нужно; `mihomo.exe` должен оставаться рядом с приложением. Разрешение администратора необходимо для TUN.

Автоматическая проверка при запуске включена для новых установок; прежнее сохранённое предпочтение не меняется. Скачивание начинается по кнопке, установка — после подтверждения перезапуска. После обновления VPN нужно запустить вручную.

Личный профиль не входит в комплект. Настройки и существующие профили в `%LOCALAPPDATA%/MorphocyteOS/Application` сохраняются. Не переноси их в архив для публикации. Профили и ключи при проверке обновлений не отправляются.

В архиве `MorphocyteOS-1.1.0-source.zip` — исходники приложения и инструкции сборки. Лицензии и соответствующие исходники Mihomo включены в комплект. Контрольные суммы архивов — в `SHA256SUMS.txt`. Приложение пока не имеет цифровой подписи; Windows может показать предупреждение SmartScreen.

# MorphocyteOS 1.0.0

Первый стабильный выпуск для Windows 11 x64.

## Возможности

- Маршруты для сайтов и приложений: VPN, прямое подключение или блокировка.
- Папки, групповое выделение Ctrl/Shift, перенос правил и изменение порядка папок.
- Импорт VLESS-ссылок, JSON Xray и готового YAML; нейтральный шаблон для нового профиля.
- Девять тем, масштаб интерфейса 80–150%, согласованные кнопки и списки, быстрые плавные анимации окон.
- Проверка стабильных обновлений вручную или при запуске по желанию.
- Ограничение резервных копий YAML, сохранение черновиков и восстановление при неудачном применении.
- Остановка собственного ядра при закрытии, защита при аварийном завершении и проверка дубликатов перед запуском.

## Установка

Скачай `MorphocyteOS-1.0.0-win-x64.zip`, распакуй весь архив и запусти `MorphocyteOS.exe`. Установка .NET не требуется. Разрешение администратора необходимо для TUN. `mihomo.exe` должен оставаться рядом с приложением.

Профиль подключения не включён: открой настройки → «VPN-профиль» → «Импорт профиля» и добавь своё подключение. По умолчанию трафик идёт напрямую, пока ты не добавишь соответствующие правила. Готовые внешние YAML используют собственные правила и завершающий маршрут.

## Обновление

Закрой предыдущую версию, распакуй новый комплект в отдельную папку и запусти новый EXE. Локальные настройки в `%LOCALAPPDATA%/MorphocyteOS/Application` сохраняются; переносить личный YAML в папку релиза не требуется.

## Ограничения

Пока нет цифровой подписи, поэтому Windows SmartScreen может показать предупреждение. Импорт HTTPS-подписок и протоколов, отличных от VLESS, не поддерживается. Работоспособность подключения зависит от своего профиля, VPN-сервера, сетевых фильтров и других VPN.

`SHA256SUMS.txt` содержит контрольные суммы архивов. `MorphocyteOS-1.0.0-source.zip` содержит исходники приложения и материалы для сборки. В комплект Windows включены соответствующие исходники Mihomo и лицензии сторонних компонентов. MorphocyteOS распространяется по GNU GPL version 3.
