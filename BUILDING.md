# Сборка MorphocyteOS

## Требования

- Windows x64 и .NET SDK 10.0.401 (закреплён в `Source/global.json`).
- Доступ к NuGet для первого восстановления зависимостей.
- Для поставляемого `mihomo.exe` Go не нужен: проверенный бинарник находится в `Source/Packaging/Engine`. Для его пересборки см. `Source/Packaging/ThirdPartySource/README.md`.

Значки для разных размеров Windows создаются из исходного PNG проектом `Source/IconAssetBuilder` перед сборкой приложения. Его исходники включены в архив релиза; вручную пересобирать ICO не требуется.

## Чистый комплект

Из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Release.ps1
```

Скрипт запускает регрессионные проверки, проверки обновлений и WPF-сценарии с безопасным тестовым ядром. Дополнительно запускает настоящий WPF-обновлятор в отдельной временной папке: проверяет передачу управления, замену файлов, повторный запуск и ошибки до закрытия приложения. Эти проверки не подключаются к VPN-серверу. Настоящее комплектное ядро используется также для проверки синтаксиса профилей без запуска TUN.

Результат находится в `artifacts/<версия из csproj>`: папка программы, ZIP для Windows x64, ZIP исходников, описание релиза, компактные пакеты обновления и один файл SHA-256 для всех этих файлов. Приложение публикуется самостоятельно запускаемым EXE со встроенной .NET Runtime 10.0.12. Mihomo остаётся отдельным EXE, sing-box расположен в `ThirdPartySource/Engine/sing-box.exe` для совместимости с обновлятором 1.2.6. Соответствующие исходники и уведомления обоих ядер включены в архивы. `release-manifest.json` содержит размеры и SHA-256 всех файлов комплекта; он нужен для безопасного встроенного обновления.

Для другого каталога:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Release.ps1 -OutputDirectory D:\Releases\MorphocyteOS-1.2.3
```

Каталог результата должен быть пустым или отсутствовать. Скрипт не очищает существующие файлы: это защищает пользовательские профили от случайной перезаписи и исключает примесь старого содержимого к релизу. Для повторной сборки укажи новую пустую папку.

В комплект и архив исходников входят только явно выбранные файлы. `.preview`, `bin`, `obj`, тестовые сборки, настройки, журналы, `portable.flag` и личные YAML не включаются. Не используй ZIP всей рабочей папки для публикации.

## Изменения и выпуск

Меняй исходники только в `Source/MorphocyteRouter`. Проекты `SubscriptionImportTests`, `RouterRegressionTests`, `UpdateServiceTests`, `UpdaterTests`, `RouterIntegrationTests` и `FakeMihomo` служат для проверок. `SubscriptionImportTests` проверяет форматы подписок, безопасную загрузку, имена серверов и ошибки на фиктивных HTTP-ответах. `UpdaterTests` проверяет загрузку, состав архива, защиту личных файлов, откат и полный цикл ожидания/установки/перезапуска на фиктивных EXE. `Source/build.ps1` собирает только комплект программы; `Scripts/Release.ps1` дополнительно готовит архивы и контрольные суммы.

Версия приложения задаётся в `Source/MorphocyteRouter/MorphocyteRouter.csproj`. При её изменении обнови README и описание релиза. При смене Mihomo обнови фиксированный SHA-256, соответствующие исходники и лицензии; при смене .NET Runtime — её закреплённую версию и лицензионные уведомления.

Перед публикацией проверь новый комплект вручную: импорт своего профиля, запуск и остановку VPN, применение правил, вкладку соединений, закрытие крестиком в трей и «Выход». Отдельно проверь включение/выключение автозапуска и вход в Windows: приложение должно появиться в трее и подключить последний сохранённый профиль без применения черновика. Проверь обновление подписки с неприменёнными правилами и восстановление VPN после сна или смены сети; ручное отключение должно отменять восстановление. Не переноси созданные при проверке файлы в ZIP. Проверки с тестовым ядром не заменяют проверку реального подключения, драйверов и совместимости с другими VPN.

Скрипты ничего не отправляют в GitHub, не создают теги и не публикуют релизы.

## Установщик Windows

ZIP остаётся самостоятельным переносимым вариантом. Для дополнительного Setup EXE нужен официальный компилятор Inno Setup 7.1 или новее. Скрипт не скачивает и не устанавливает компилятор сам.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Release.ps1 -WithInstaller -InstallerCompilerPath "C:\Tools\InnoSetup\ISCC.exe" -OutputDirectory D:\Releases\MorphocyteOS-setup
```

В результат и `SHA256SUMS.txt` добавится `MorphocyteOS-<версия>-Setup.exe`. Состав установщика формируется только из проверенного чистого комплекта и отдельного служебного EXE удаления: настройки, личные профили, журналы и локальные тестовые демонстрации не упаковываются. Проверки `InstallerTests` работают на искусственных файлах; `Test-Installer.ps1` проверяет состав и защитные ограничения без установки в Windows.

Мастер оформлен в зелёно-бирюзовой стилистике MorphocyteOS; светлый или тёмный вариант выбирается по теме Windows. Боковые иллюстрации, небольшой прозрачный значок и фоны обоих вариантов генерируются проектом `Source/InstallerArtworkBuilder` из исходного значка приложения. Собственная шапка заменяет обычную рамку Windows; оформление работает без сторонних модулей или DLL-скинов. Кнопки и поля остаются элементами самого Inno Setup, с обычной клавиатурной навигацией. При высокой контрастности Windows или запуске с `/NOSTYLE` восстанавливаются системная рамка, фон и читаемые цвета. `Installer/Branding.iss`, `Installer/WindowChrome.iss`, все изображения и исходники генератора включены в архив исходников.

Для просмотра страниц **без установки**, если чистый комплект программы и служебный EXE удаления уже собраны:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Build-Installer.ps1 -PackageDirectory "D:\Releases\MorphocyteOS-1.2.7-win-x64" -MaintenanceHelperPath "D:\Releases\helper\MorphocyteOS-maintenance.exe" -OutputDirectory "D:\Releases\setup-preview" -IsccPath "C:\Tools\InnoSetup\ISCC.exe" -TestInstaller -PreviewOnly
```

Результат `MorphocyteOS-<версия>-Setup-Test-Preview.exe` показывает приветствие, лицензию, выбор папки, дополнительные задачи и итоговую страницу. Этот отдельный EXE не требует прав администратора, не содержит установочных файлов, ярлыков или действий запуска, не регистрирует приложение; переход к установке заблокирован. После просмотра закрой мастер кнопкой «Отмена». Режим `-PreviewOnly` нельзя использовать вместо настоящего Setup для публикации.

Для отдельной визуальной проверки обоих вариантов добавь к команде просмотра `-PreviewTheme light` или `-PreviewTheme dark` и используй разные пустые каталоги результата. Это не меняет тему Windows; принудительный вариант разрешён только вместе с `-PreviewOnly`. Полноценный установщик всегда выбирает оформление по настройке Windows.

Для локальной пробы добавь `-TestInstaller`: имя будет `MorphocyteOS-<версия>-Setup-Test.exe` и отдельная запись удаления «MorphocyteOS (тест установщика)». Конечная папка в обоих вариантах называется `MorphocyteOS`; при выборе другого расположения имя добавляется к выбранному пути без дублирования. Тестовая и основная установка должны находиться в разных родительских папках. Это отдельная установка, **но не отдельные пользовательские данные**: приложение использует обычные настройки MorphocyteOS и выбранные ранее профили. Не запускай её одновременно с основной версией.

Установщик предлагает папку и ярлык в «Пуске». В дополнительных задачах доступны ярлык рабочего стола и «Запустить MorphocyteOS после установки»; обе отметки изначально выключены. Приложение запускается только при явном выборе этой задачи и не запускается при тихой установке. Запуск инициируется оболочкой исходного пользователя с запросом UAC, поскольку приложение требует прав администратора; установщик не включает автозапуск и не передаёт команду включения VPN. Учти, что приложение использует существующие пользовательские настройки, включая ранее выбранный режим запуска. Перед установкой или удалением закрой приложение через «Выход» в трее: крестик только сворачивает окно. Установщик не завершает приложение или другие VPN сам.

Первичная установка требует пустую отдельную папку; существующая переносимая копия не перезаписывается. Повторный Setup может восстановить идентифицированную установку той же версии только при неизменённых файлах комплекта. Обновление до новой версии выполняется встроенным обновлятором; установочные отметки при этом сохраняются, версия в списке установленных приложений обновляется после успешного запуска новой версии.

Удаление доступно через «Установленные приложения» Windows. Оно проверяет текущий манифест и удаляет только неизменённые файлы программы, включая добавленные встроенным обновлением. Личные профили, настройки, заменённые ядра и изменённые файлы сохраняются. Каталог целиком рекурсивно не удаляется. Отдельный служебный EXE фиксируется контрольной суммой в удаляющей программе и не заменяется встроенными обновлениями; удаление не исполняет приложение по доверенной на слово контрольной сумме из изменяемого манифеста.

Подпись Authenticode для нашего Setup пока не настроена: Windows может показать предупреждение о неизвестном издателе. Компиляция и автоматические проверки не заменяют ручную пробу установки, ремонта, обновления и удаления на чистой Windows.

Для работы встроенной загрузки публикуй стабильный GitHub Release с тегом `v<версия>` и всеми подготовленными файлами: `MorphocyteOS-<версия>-win-x64.zip`, `MorphocyteOS-<версия>-source.zip`, `MorphocyteOS-<версия>-update.json`, **все** `MorphocyteOS-part-<sha256>.zip`, `SHA256SUMS.txt`. У файлов должен быть `digest: sha256:…` в метаданных GitHub API; полный архив должен содержать сгенерированный манифест и `release-source.json`. Изменять файлы после проверки или упаковывать вместо них свою тестовую папку нельзя. Предварительные релизы и файлы без проверяемой контрольной суммы не предлагаются для установки.

Новый обновлятор сначала сравнивает размеры и SHA-256 установленных файлов с индексом `MorphocyteOS-<версия>-update.json`. Он скачивает только сжатые компоненты, в которых есть изменённые, повреждённые или отсутствующие файлы. EXE приложения, каждое ядро и каждый большой архив исходников находятся в отдельных компонентах; небольшие лицензии и документы объединены, чтобы не выполнять сотни отдельных запросов. Если поменялось только приложение, ядра и их исходники повторно не скачиваются. Полный ZIP оставлен для ручной установки, старых клиентов и релизов без нового индекса. Повреждённый индекс не заменяется молча полной загрузкой.

Индекс формата `SchemaVersion: 1` содержит полный `Manifest` (обычный `release-manifest.json`) и `Packages`: имя, сжатый размер, SHA-256 и список относительных путей для каждого компонента. ZIP содержит только перечисленные файлы с прямыми относительными путями, без верхней папки и без самого манифеста. Все компоненты вместе покрывают каждый управляемый файл ровно один раз. Фиксированные даты ZIP и сортировка путей сохраняют имена/контрольные суммы неизменённых компонентов между сборками.

Проверить упаковку без пересборки приложения можно командой `powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Test-UpdateAssets.ps1`. Она использует только искусственные файлы во временной папке и не запускает приложение или VPN. Для формирования компонентов уже проверенного чистого комплекта можно загрузить функции из `Scripts/UpdateAssets.ps1` и вызвать `New-IncrementalUpdateAssets -PackageDirectory <папка-комплекта> -OutputDirectory <папка-артефактов> -ExpectedVersion <версия>`; существующий индекс или компоненты не перезаписываются.
