# MorphocyteOS

Приложение для Windows, которое управляет VPN-подключением и правилами маршрутизации через sing-box. Mihomo доступен как альтернативное ядро. Для подключения нужен свой профиль или ссылка от VPN-провайдера.

## Что умеет

- Отправлять трафик отдельных сайтов и приложений через VPN, напрямую или блокировать его.
- Переключать TUN: VPN для всего трафика по умолчанию, с сохранением явных исключений «Напрямую» и блокировок. VPN-правила в этом режиме приглушены, но остаются редактируемыми; новый маршрут применяется кнопкой «Применить в YAML». Выключение TUN возвращает обычные правила; работающее подключение кратковременно перезапускается. Тумблер сам не меняет YAML и не применяет черновики.
- Импортировать YAML, VLESS-ссылки, JSON Xray и HTTPS-подписки. Обновлять подписку с сохранением правил и папок.
- Группировать правила в папки, менять маршрут прямо в списке, отменять и повторять изменения через Ctrl+Z / Ctrl+Y.
- Показывать трафик, задержку подключения, журнал и активные соединения. Проверять подключение по этапам и копировать диагностику без данных профиля.
- В тестовой версии общий TUN сохраняет DNS-политики и резервные серверы профиля; стандартный одиночный DNS получает резервный HTTPS-сервер. По умолчанию используются стек gvisor и MTU 1280, явно заданные пользовательские MTU и стек system сохраняются. Проверка подключения при общем TUN дополнительно выполняет короткий HTTPS-запрос через системную сеть без локального прокси. Это проверка доступности, а не гарантия маршрутизации каждого приложения.
- По кнопке «Скорость» оценивать скорость приёма через VPN и показывать текущую загрузку относительно результата. Замер скачивает тестовые данные Cloudflare (до 64 МБ, до 15 секунд), отменяется повторным нажатием и не отправляет данные профиля. Процент учитывает входящий трафик ядра, в том числе прямые маршруты в режиме правил; это оценка, не обещание максимальной скорости провайдера. Результат сбрасывается при перезапуске VPN или смене сети/сервера.
- Работать в трее, подключать последний профиль при входе в Windows и восстанавливать работавший VPN после сна или смены сети.
- Переносить подключение, правила и настройки одним файлом `.morphocyte`.
- Обновляться из релизов GitHub. Автоматическая установка ждёт выключения VPN.

## Как запустить

1. Скачай [релиз для Windows x64](https://github.com/Rabotaet3/MorphocyteOS/releases) и распакуй весь архив.
2. Запусти `MorphocyteOS.exe` с правами администратора. Файл `mihomo.exe` должен оставаться рядом.
3. В настройках открой «VPN-профиль» и импортируй подключение или выбери готовый YAML.
4. Добавь правила, нажми «Применить в YAML» и запусти VPN.

Приложение рассчитано на Windows 11 x64. Устанавливать .NET отдельно не нужно.

Изменения правил остаются черновиком до применения. Крестик сворачивает окно в трей; пункт «Выход» останавливает VPN и закрывает приложение.

Файл экспорта содержит данные подключения — передавай его только тем, кому доверяешь доступ к своему VPN.

Если обновление из 1.2.1 или 1.2.2 закрывает программу без установки, один раз закрой её и распакуй полный архив 1.2.3 в ту же папку с заменой файлов. Личные профили и настройки сохраняются.

## Основное ядро sing-box

Начиная с версии 1.2.7 **sing-box 1.14.2** — основное ядро по умолчанию. При первом запуске этой версии прежнее комплектное ядро Mihomo заменяется в настройках на sing-box; пользовательские исполняемые файлы сохраняются. Последующий ручной выбор Mihomo не сбрасывается. Ядро можно выбрать в настройках VPN-профиля, в поле «Ядро подключения». Перед сменой остановите VPN. Для Windows TUN нужны права администратора. Другие VPN-программы с TUN должны быть остановлены.

Исходный YAML не переписывается в JSON: JSON создаётся только на время работы ядра. В полном режиме неизвестный трафик идёт в VPN, явные правила DIRECT и блокировки сохраняются. При выключенном полном режиме действует список правил и его обычный завершающий маршрут.

Это не универсальная поддержка любых Clash-профилей. Поддерживаются простые подключения VLESS, VMess, Trojan, Shadowsocks, SOCKS5 и HTTP, группы select/url-test, доменные правила, процессы, пути процессов, IP-подсети, отдельные порты и TCP/UDP. TLS/Reality, WS/HTTPUpgrade и gRPC поддерживаются для подходящих протоколов. Proxy providers, GEOIP/GEOSITE, RULE-SET, составные правила и дополнительные неподдерживаемые настройки будут отклонены; профиль останется прежним.

В адаптере sing-box учитываются nameserver, direct-nameserver, числовые bootstrap-серверы, простые доменные nameserver-policy и fake-ip-filter, а также отключение DNS IPv6. Несколько DNS-серверов опрашиваются параллельно; обычные запросы отправляются через VPN, без прямого резервного маршрута. Сложные DNS-политики отклоняются вместо молчаливой потери настроек. Настройки TUN генерируются приложением.

После смены сети восстановление проверяет и VPN-сервер, и системный HTTPS-путь общего TUN. Неожиданное завершение ядра вызывает ограниченное число попыток восстановления; ручная остановка отменяет их. Включён локальный Fake-IP-кэш рядом с выбранным профилем (`.morphocyte-singbox-*.db`); он содержит имена посещённых доменов, не включается в сборку и не должен публиковаться. В sing-box 1.14.2 аварийное завершение может нарушить сохранение этого кэша, поэтому полная устойчивость Fake-IP после жёсткого сбоя пока не гарантируется.

Для возврата выберите Mihomo и сохраните настройки. Комплектный sing-box размещён в `ThirdPartySource/Engine`, чтобы обновлятор прежних версий мог безопасно установить новое ядро вместе с программой.
