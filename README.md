# Морфоцит OS

Переносимый VPN-клиент для Windows x64 с глобусом для выбора серверов, правилами для сайтов и приложений и управлением из трея. Для подключения понадобится подписка или собственный VPN-профиль.

## Установка

1. Скачай ZIP или RAR со страницы [релизов Морфоцита](https://github.com/Rabotaet3/MorphocyteOS/releases/latest).
2. Распакуй архив целиком и запусти `MorphocyteAtlas.exe`. Приложению нужны Microsoft Edge WebView2 Runtime и права администратора для TUN.
3. Нажми «Ссылка подписки» на вкладке «Подключение». Для YAML или JSON Xray открой «Настройки → VPN-профиль».

Настройки и профили хранятся в папке `backend` рядом с программой. При переносе на другой компьютер добавь ссылку подписки заново.

## Серверы и маршруты

- На вкладке «Серверы» можно искать по названию и стране, обновлять подписку и запускать проверку по кнопке «Пинг». Режим «Через VPN» измеряет время HTTPS-запроса через профиль. TCP и ICMP доступны при выключенном VPN.
- На вкладке «Маршруты» можно направить трафик сайта, IP-адреса или приложения через VPN, напрямую или заблокировать. Кнопка «Запущенные процессы» открывает список приложений. Для выбора диапазона используй Shift, затем нажми «Добавить выбранные» и «Применить».
- Подписку, YAML-профиль и правила можно обновлять при включённом VPN. Морфоцит проверяет изменившуюся конфигурацию и при необходимости переподключается. Если новый профиль не запустился, Морфоцит пробует восстановить прежнее подключение.
- На вкладке «Подключение» видны текущий трафик и последний успешный пинг выбранного сервера. «Проверить» запускает замер скорости приёма через VPN. В «Журнале» доступны события и список соединений.

## Настройки и обновления

Анимации включены по умолчанию. Чтобы отключить их, открой «Настройки → Анимации», сними галочку и нажми «Сохранить». В настройках также доступны темы, масштаб интерфейса, прозрачность панелей и параметры запуска.

Крестик убирает окно в трей. Правой кнопкой по значку можно открыть меню, сменить тему, управлять VPN или полностью выйти из приложения.

В «Настройки → Обновления» можно проверить новую версию вручную или включить автоматическую проверку. «Установить» скачивает полный ZIP, проверяет SHA-256 и перезапускает Морфоцит. Профили, подписка и настройки сохраняются. «Позже» закрывает предложение об обновлении.

## Сборка из исходников

Скачай архив `-source.zip` и распакуй переносимую сборку из того же релиза. Для сборки нужны Python, Rust и инструменты сборки Windows. Передай скрипту путь к папке `backend` из переносимой сборки.

```powershell
.\build.ps1 -EngineAssetsDirectory 'C:\MorphocyteAtlas\backend'
```

Готовый комплект появится в `dist-native-<версия>`. Флаг `-PortableArchive` создаёт ZIP, RAR и контрольные суммы. Для RAR нужен WinRAR.

Основное ядро — sing-box. Для совместимых профилей Xray запускается автоматически. Лицензии и сведения об исходниках ядер находятся в `backend`.
