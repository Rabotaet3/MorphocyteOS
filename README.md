# MorphocyteOS · 1.1.1

Приложение для Windows 11 x64: редактор маршрутов и оболочка для ядра Mihomo. Это не VPN-сервис — для подключения нужен собственный профиль или ссылка от VPN провайдера.

## Первый запуск

1. Распакуй весь ZIP-архив в отдельную папку. `MorphocyteOS.exe` и `mihomo.exe` должны лежать рядом.
2. Запусти `MorphocyteOS.exe` и разреши запрос администратора: эти права нужны для TUN.
3. Открой настройки → «VPN-профиль» → «Импорт профиля». Вставь HTTPS-ссылку на подписку, `vless://` ссылку или JSON Xray с одним VLESS-подключением. JSON можно открыть из файла; готовый YAML выбирается в настройках.
4. Добавь сайты или приложения, выбери для них маршрут, нажми «Применить в YAML», затем запусти VPN.

Встроенный YAML-шаблон нейтральный: в нём нет сервера, ключей и чужих правил. Пока подключение не добавлено, запуск VPN заблокирован. При первом запуске ядро не запускается автоматически.

Устанавливать .NET не нужно: среда исполнения включена в приложение. Mihomo 1.19.31 поставляется отдельным EXE. В настройках можно выбрать другое доверенное ядро или вернуться к комплектному. Профиль и ядро выбираются независимо.

## Импорт и маршрутизация

HTTPS-импорт принимает YAML Clash/Mihomo со списком `proxies`, JSON Xray с одним VLESS-сервером и списки VLESS-ссылок (текст или Base64). Из подписки переносятся только серверы: чужие правила, DNS, контроллер и открытые порты не копируются. Создаётся отдельный профиль с нейтральной маршрутизацией. Подписка загружается по нажатию; автоматическое обновление её содержимого пока не реализовано.

Поддерживаются VLESS TCP (включая Vision), WebSocket, gRPC, HTTPUpgrade, TLS и Reality. YAML может содержать другие поддерживаемые импортом типы серверов; результат проверяется выбранным ядром. URI других протоколов, YAML только с `proxy-providers`, якоря и зависимости от локальных файлов пока отклоняются. Допустимы до 200 серверов, 1 МБ загрузки и 256 тысяч символов текста. HTTP, локальные адреса и небезопасные перенаправления запрещены; ошибки не раскрывают приватную ссылку.

HTTPS-запрос передаёт ссылку серверу подписки и его HTTPS-перенаправлениям. При VPN Fake-IP имя сайта разрешается через HTTPS DNS Cloudflare/Google без пути и ключа подписки. Ссылка не сохраняется в журнале или созданном YAML.

Название одиночного VLESS-сервера берётся из части ссылки после `#`, включая эмодзи и кириллицу. Если у одиночного подключения нет названия, открывается окно ввода имени; отмена не меняет текущий профиль. В многосерверной подписке безымянные серверы получают номера. Отключение проверки TLS требует подтверждения.

При преобразовании Xray DNS, routing и inbounds не переносятся: создаётся профиль Mihomo с TUN и `MATCH,DIRECT`. Через VPN идут добавленные правила, остальное — напрямую. Готовый YAML загружается с исходным путём; его соседние provider/geodata-файлы должны оставаться доступными. Для применения маршрутов нужны `mode: rule` и `tun: { enable: true }`.

Импорт подключения создаёт новый YAML, не перезаписывая исходный файл. Применение правил изменяет выбранный YAML; рядом сохраняются три последние резервные копии.

## Правила и папки

- «Весь домен»: сайт и его поддомены, например `example.com` и `shop.example.com`.
- «Точное имя»: только указанный адрес; `www.example.com` отличается от `example.com`.
- «По слову»: адрес содержит указанный фрагмент, например `google` в `mail.google.com`.
- «Процесс .exe»: соединения приложения по имени файла. Программу также можно выбрать из списка запущенных процессов.

Ctrl + клик выделяет несколько правил; Shift + клик — диапазон. Галочка выделенного правила переключает всю выделенную группу. Галочка папки переключает все её правила, включая скрытые поиском. Правила и папки можно перетаскивать; список прокручивается колесиком во время переноса. Удаление папки переносит правила в общие, а не удаляет их.

В списке запущенных приложений Ctrl + клик выбирает несколько приложений, Shift + клик — диапазон. Через «Выбрать .exe» тоже можно выбрать несколько файлов. После выбора приложения сразу добавляются в черновик правил; YAML не меняется до нажатия «Применить в YAML».

Редактор показывает DOMAIN, DOMAIN-SUFFIX, DOMAIN-KEYWORD и PROCESS-NAME; прочие правила исходного YAML сохраняются. DIRECT — напрямую, REJECT — блокировка. Удаление правила процесса не гарантирует прямой маршрут: могут совпасть другие правила или MATCH. Уже открытые соединения могут потребовать перезапуска приложения, трафик которого ты проверяешь.

## Настройки и обновления

Доступны девять тем и масштаб 80–150%, включая шрифты и дополнительные окна. «Сохранить» применяет настройки, не закрывая окно. Журнал можно скрыть нижним переключателем.

Настройки и созданные профили хранятся в `%LOCALAPPDATA%/MorphocyteOS/Application`. Установленное ранее пользовательское ядро и выбранный профиль сохраняются. Журнал может содержать адреса посещённых ресурсов: проверь его перед отправкой.

Проверка обновлений использует стабильные релизы `Rabotaet3/MorphocyteOS` на GitHub; предварительные релизы пропускаются. Для новых установок проверка при запуске включена; прежнее сохранённое предпочтение не меняется. Её можно выключить в настройках → «Обновления», где доступна и ручная проверка. Если есть новая версия с проверенным архивом Windows x64, появляется кнопка «Загрузить актуальную версию: …». Если обновления нет, кнопка загрузки скрыта. Профили и ключи при проверке не отправляются.

По кнопке приложение загружает архив прямо с GitHub, проверяет SHA-256 и состав файлов. После подтверждения перезапуска останавливает своё ядро и заменяет файлы комплекта; удаляет только устаревшие файлы, перечисленные в прежнем `release-manifest.json` и не изменённые пользователем. Личные YAML, настройки и выбранное пользовательское ядро сохраняются. При ошибке выполняется откат; при незавершённом откате резервные файлы сохраняются. После обновления VPN нужно запустить вручную.

Комплект без `release-manifest.json` (например, 1.0.0) нужно обновить вручную один раз: закрыть приложение и распаковать новый комплект в отдельную папку. Дальнейшие обновления выполняются внутри приложения. Закрытие крестиком останавливает принадлежащее ему ядро; сторонние копии Mihomo не завершаются без подтверждения.

## Ограничения

Подключение зависит от профиля, сервера, драйверов, других VPN и сетевых фильтров. Проверка YAML подтверждает корректность настроек, но не доступность сервера. Приложение пока не имеет цифровой подписи: Windows может показать предупреждение SmartScreen. Скачивай комплект со страницы релизов проекта и при необходимости сверяй SHA-256.
