# Mihomo Go dependency notices

The license and notice files in this directory are copied from the exact Go modules listed in the pinned Mihomo `go.mod`/`go.sum` and included in `ThirdPartySource/mihomo-v1.19.31-corresponding-source.tar.gz`.

Module versions and complete corresponding source are preserved in that archive's `vendor/modules.txt` and `vendor/` tree. The upstream `github.com/metacubex/chacha` module omits a referenced `LICENSE` file; its copied ChaCha implementation identifies Andreas Auernhammer and refers to that file. The MIT text for its source project, `github.com/aead/chacha20`, is provided as `../Mihomo-chacha-MIT.txt`.
