# MorphocyteOS

Приложение для Windows, которое управляет VPN-подключением и правилами маршрутизации через ядро Mihomo. Для подключения нужен свой профиль или ссылка от VPN-провайдера.

## Что умеет

- Отправлять трафик отдельных сайтов и приложений через VPN, напрямую или блокировать его.
- Импортировать YAML, VLESS-ссылки, JSON Xray и HTTPS-подписки.
- Группировать правила в папки и менять маршрут прямо в списке.
- Показывать трафик, задержку подключения, журнал и активные соединения.
- Работать в трее и подключать последний профиль при входе в Windows.
- Переносить подключение, правила и настройки одним файлом `.morphocyte`.
- Обновляться из релизов GitHub. Автоматическая установка ждёт выключения VPN.

## Как запустить

1. Скачай [релиз для Windows x64](https://github.com/Rabotaet3/MorphocyteOS/releases) и распакуй весь архив.
2. Запусти `MorphocyteOS.exe` с правами администратора. Файл `mihomo.exe` должен оставаться рядом.
3. В настройках открой «VPN-профиль» и импортируй подключение или выбери готовый YAML.
4. Добавь правила, нажми "Применить в YAML" и запусти VPN.

Приложение рассчитано на Windows 11 x64. Устанавливать .NET отдельно не нужно.

Изменения правил остаются черновиком до применения. Крестик сворачивает окно в трей; пункт «Выход» останавливает VPN и закрывает приложение.

Файл экспорта содержит данные подключения, передавай его только тем, кому доверяешь доступ к своему VPN.
