# MorphocyteOS · 1.0.0-rc.5

Кандидат в релиз для Windows 11 x64. Это редактор правил и оболочка для ядра Mihomo, а не сервис, выдающий VPN-подключения.

## Первый запуск

1. Распакуй `MorphocyteOS.exe` и `mihomo.exe` из ZIP-архива в одну папку, затем запусти `MorphocyteOS.exe`. Не переименовывай ядро. Для TUN требуется разрешение администратора.
2. Нейтральный YAML-шаблон встроен в приложение; Mihomo 1.19.31 поставляется рядом отдельным EXE. В комплекте нет VPN-сервера, ключей или готовых пользовательских правил. Отдельной заставки первого запуска нет.
3. Чтобы импортировать подключение, открой настройки → «VPN-профиль» → «Импорт профиля». Вставь свою `vless://` ссылку или JSON Xray с одним VLESS-подключением. Можно открыть файл JSON или готовый YAML. Программа проверит YAML и загрузит его, сохранив исходный путь и соседние файлы.
4. Поддерживаются TCP (включая Vision), WebSocket, gRPC, HTTPUpgrade, TLS и Reality. DNS, routing и inbounds Xray не переносятся: создаются настройки для Mihomo с TUN и `MATCH,DIRECT`. Через VPN идут добавленные правила, остальной трафик — напрямую. HTTPS-подписки и другие протоколы пока не импортируются. Неподдерживаемые настройки подключения отклоняются с объяснением. Отключённая проверка TLS требует подтверждения.
5. Запусти VPN. Добавь сайт или процесс, выбери маршрут и нажми «Применить в YAML».

Программа не требует установленного .NET: среда исполнения включена в `MorphocyteOS.exe`. Соседний `mihomo.exe` проверяется по SHA-256 и запускается отдельным процессом; для ресурсов и кеша используется папка выбранного YAML. Импортированные профили не перезаписывают исходные файлы. Пустой шаблон можно редактировать, но запуск VPN без подключения заблокирован. Генерируемые профили не требуют файлов geodata.

В настройках можно выбрать другое доверенное ядро `.exe` или вернуться к `mihomo.exe`, поставляемому рядом с приложением. Уже выбранные пользовательские ядро и профиль сохраняются при обновлении. Для внешнего YAML нужны `mode: rule` и `tun: { enable: true }`; его относительные provider/geodata-файлы должны лежать в доступной для записи папке профиля.

## Правила и папки

«Сайт и его поддомены» охватывает, например, `example.com` и `shop.example.com`. «Только этот сайт» совпадает лишь с указанным адресом: `www.example.com` считается отдельно от `example.com`. «Адрес содержит слово» ищет фрагмент имени, например `google` в `mail.google.com`. «Вся программа (.exe)» направляет соединения приложения по имени файла; его также можно выбрать среди запущенных процессов. Наведи курсор на вариант, чтобы увидеть пример.

Ctrl + клик выделяет несколько правил; Shift + клик — диапазон. Галочка выделенного правила переключает всю выделенную группу. Галочка папки переключает все её правила, даже скрытые поиском. Правила и папки можно перетаскивать, а список — прокручивать во время переноса. Удаление папки переносит её правила в общие, не удаляя их.

Редактор показывает DOMAIN, DOMAIN-SUFFIX, DOMAIN-KEYWORD и PROCESS-NAME. Прочие правила исходного YAML сохраняются. Удаление правила процесса не означает, что его трафик обязательно станет прямым: совпасть могут другие правила или MATCH. DIRECT — напрямую, REJECT — блокировка.

Настройки, папки, выключенные правила и черновики сохраняются локально в `%LOCALAPPDATA%/MorphocyteOS/Application`. Эта сборка не подхватывает настройки старой тестовой программы автоматически. Изменения начинают действовать после применения. Для YAML остаются три последние резервные копии рядом с профилем. Журнал можно скрыть нижним переключателем; он может содержать адреса посещённых ресурсов, поэтому перед отправкой его стоит проверить.

## Оформление и обновления

В настройках доступны девять тем и масштаб 80–150%, включая шрифты, кнопки и дополнительные окна.

Автоматическая проверка обновлений по умолчанию выключена. При включении программа проверяет релиз при запуске и предлагает открыть страницу загрузки; не скачивает и не запускает обновления без участия пользователя.

Сейчас источник обновлений не настроен, поэтому проверить наличие новой версии нельзя. Когда проверка доступна, приложение обращается по HTTPS к GitHub только за сведениями о стабильном релизе; YAML и ключи туда не передаются. Обновление не скачивается и не устанавливается без участия пользователя.

Это предварительная версия (RC), и подключение зависит от профиля, сервера, драйверов, других VPN и сетевых фильтров. Файл приложения пока не имеет цифровой подписи; Windows может показать предупреждение SmartScreen.
