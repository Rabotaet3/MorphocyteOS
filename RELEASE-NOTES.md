# MorphocyteOS 1.3.6

- Исправлено мерцание окна при быстрой прокрутке списков и обновлении подписки. Плавная прокрутка и оформление тем сохранены.
- Улучшены переходы между вкладками. Журнал соединений сохраняет положение списка при обновлении счётчиков трафика.
- Обновление подписки точнее восстанавливает выбор сервера. При неполном ответе провайдера текущий список сохраняется до подтверждения.
- Подготовка запуска VPN выполняется в фоне. Автоподключение при открытии можно включить в настройках.
- Тумблер TUN снова переключает полный туннель и маршрутизацию по профилю. Локальный прокси включается отдельно.
- Обновлён раздел «ЧаВо?».

Для установки скачайте **MorphocyteOS-1.3.6-Setup.exe**. Для запуска без установки скачайте **MorphocyteOS-1.3.6-win-x64.zip**. Встроенное обновление запускается вручную.
