# MorphocyteOS 1.2.7

- sing-box 1.14.2 теперь основное ядро по умолчанию. Прежний комплектный Mihomo переключается на sing-box при первом запуске 1.2.7; пользовательские ядра сохраняются. Mihomo доступен как альтернатива, последующий ручной выбор не сбрасывается. Перед сменой ядра останови VPN.
- Исправлен приоритет доменных исключений: изменение существующего правила на «Напрямую» или «Блокировка» больше не оставляет его позади общего VPN-правила приложения.
- Общий TUN сохраняет именованные прямые маршруты и группы, содержащие только прямые маршруты или только блокировки. VPN остаётся завершающим маршрутом для остального трафика.
- Устойчивее DNS: независимые резервные серверы, поддержка простых DNS-политик в адаптере sing-box, сохранение запрета DNS IPv6. Ошибочный ответ первого DNS не мешает получить корректный ответ второго; обычные запросы не переключаются на прямой маршрут при отказе VPN-DNS.
- Восстановление после смены сети проверяет не только VPN-сервер, но и системный HTTPS-путь TUN. Сетевые изменения во время запуска откладываются, а не теряются. После аварийного завершения ядра выполняются ограниченные попытки восстановления; ручная остановка отменяет их.
- Уточнены ошибки проверки и улучшен профиль TUN по умолчанию: gvisor и MTU 1280. Сохранены явные настройки Mihomo для MTU и стека system.

## Установка и обновление

Скачай `MorphocyteOS-1.2.7-win-x64.zip` и распакуй весь комплект. Доступно встроенное обновление с 1.2.6. При ручном обновлении закрой приложение через «Выход» в трее и замени файлы программы. Профили и настройки сохраняются; .NET отдельно не нужен.

Для TUN нужны права администратора. Другие приложения с TUN должны быть остановлены. В настройках «VPN-профиль» выбери ядро, сохрани настройки и запусти VPN. Правила «Напрямую» и блокировки продолжают действовать; изменения правил применяются кнопкой «Применить в YAML».

## Ограничения sing-box

Поддерживаются не все возможности Clash YAML. Неизвестные подключения, сложные DNS-политики, providers, GEOIP/GEOSITE и RULE-SET отклоняются без изменения исходного профиля. При несовместимости можно выбрать Mihomo.

Включено сохранение локального Fake-IP-кэша, но sing-box 1.14.2 может потерять его после аварийного завершения. Полная устойчивость Fake-IP после жёсткого сбоя не гарантируется. Реальная доступность VPN также зависит от сервера и сети провайдера.

Исходники, лицензии и соответствующие исходники обоих ядер включены в комплект; контрольные суммы архивов — в `SHA256SUMS.txt`. Личные YAML, ссылки, ключи, настройки, журналы и DNS-кэш не включены в релиз.

## Ограничения

Пока нет цифровой подписи, поэтому Windows SmartScreen может показать предупреждение. Импорт HTTPS-подписок и протоколов, отличных от VLESS, не поддерживается. Работоспособность подключения зависит от своего профиля, VPN-сервера, сетевых фильтров и других VPN.

`SHA256SUMS.txt` содержит контрольные суммы архивов. `MorphocyteOS-1.0.0-source.zip` содержит исходники приложения и материалы для сборки. В комплект Windows включены соответствующие исходники Mihomo и лицензии сторонних компонентов. MorphocyteOS распространяется по GNU GPL version 3.
