# Морфоцит OS

Переносимая сборка Windows x64. Распакуй ZIP или RAR целиком и запусти **MorphocyteAtlas.exe**. Для окна нужен Microsoft Edge WebView2 Runtime. Windows запрашивает права администратора при запуске. Главное окно открывается развёрнутым. Кнопка восстановления возвращает сохранённый обычный размер.

Rust управляет окном, импортом подписок, маршрутами, журналом и проверкой серверов. Морфоцит запускает sing-box и при необходимости Xray как дочерние процессы. Сборка работает без модуля 1.3.6 и .NET. Настройки и профили сохраняются в папке `backend`. Ссылка подписки и ID устройства защищены средствами Windows и привязаны к пользователю. При переносе на другой компьютер добавь ссылку заново.

Использованы все девять палитр 1.3.6. Значки окна, панели задач и трея меняются вместе с темой. В меню трея каждая кнопка темы окрашена в её собственные цвета. Из трея также можно открыть настройки или журнал, запустить или остановить VPN. Крестик убирает окно в трей, если Windows приняла значок. «Выход» в меню трея останавливает VPN и закрывает Морфоцит.

На странице «Подключение» можно измерить максимальную скорость приёма через текущий VPN-сервер. Морфоцит скачивает тестовые данные Cloudflare и при сбое пробует Hetzner через тот же VPN. Общий лимит замера — 64 МБ и 24 секунды. «Задержка» показывает последний успешный замер выбранного сервера.

При отключённом VPN в списке серверов можно выбрать TCP для проверки порта или ICMP для проверки адреса. Проверка «Через VPN» отправляет HTTPS-запрос через выбранный профиль и использует доверенные сертификаты Windows.

В «Маршрутах» кнопка «Запущенные процессы» открывает список приложений с окнами на всю доступную высоту. Отметь галочками несколько приложений или выбери диапазон с Shift, укажи маршрут и нажми «Добавить выбранные». Правила появятся в черновике, который сохраняется кнопкой «Применить».

В «Настройки → Запуск» можно включить запуск при входе в Windows и отдельно выбрать, когда подключать VPN. При запуске из автозагрузки Windows показывает запрос прав администратора. После переноса папки программы настрой автозапуск из нового расположения.

В «Настройки → Обновления» можно проверить новый релиз вручную или включить проверку при запуске. «Установить» скачивает полный ZIP из GitHub Releases, проверяет SHA-256, заменяет файлы приложения и перезапускает Морфоцит. «Позже» закрывает уведомление. Профили, подписка и настройки хранятся отдельно от обновляемых файлов.

## Сборка

Для сборки нужны Python, Rust и компоновщик Windows. Передай в `-EngineAssetsDirectory` папку `backend` из распакованной Rust-сборки. Скрипт возьмёт из неё ядра, лицензии и сведения об исходниках. Сборка появится в `dist-native-1.4.1`. Флаг `-PortableArchive` создаёт ZIP, RAR и их контрольные суммы. Для упаковки в RAR нужен WinRAR.

Для регрессионных проверок старого модуля можно явно указать `-Release136Directory`. Этот режим использует .NET 10 SDK и пишет в отдельную папку `dist-1.4.1`.

Геометрия карты входит в исходники как ui/border-view.json. После изменения исходной геометрии её можно пересобрать через build-map.py с установленным Shapely.

После изменения `ui/morphocyte-mark.svg` или `ui/icon-palettes.json` запусти `python build-icons.py`, чтобы обновить значки Windows перед сборкой. Для этой команды нужен Microsoft Edge.

## Переносимая сборка

Сборка с `-PortableArchive` готовит два файла.

- `MorphocyteOS-1.4.1-portable-win-x64.zip`
- `MorphocyteOS-1.4.1-portable-win-x64.rar`
- Файлы `.sha256` для обоих архивов

В ZIP входят приложение, ядра и лицензии. Рабочие настройки, подписки, ID устройства, профили и журналы в архив не включаются. Пользователю нужно распаковать ZIP целиком и открыть `MorphocyteAtlas.exe`.
